A chaotic and fun Minecraft Fabric mod designed for co-op challenges, survival races, and multiplayer games with friends! Destroy specific block types around you using **your actual voice**.

---

## 🚀 Features & Current State

* 🗣 **Voice-Activated Block Destruction:** Destroy blocks around you by simply saying their names out loud into your microphone (requires **Plasma Voice**).
* 🌐 **Language Support:**
  * **English**
  * **Russian**
  * 🌍 **Other Languages** — Planned based on community requests in our Discord.
* 🖥 **In-Game GUI:** Currently in **Early Access**. Expect improvements in upcoming releases!
* ⚡ **Co-op Focused:** Ideal for competitive survival, mini-games, and stream events.

---

## 🛠 Deprecated Features

* ⚠️ **`/destroy` Command:** The `/destroy <block> <radius>` command is still present in the mod, but **it is deprecated, inconvenient to use, and no longer updated/maintained**. We strongly recommend using voice control or the in-game GUI instead.

---

## 📦 Requirements & Installation

### Dependencies
Make sure you have the following mods installed:
* **Fabric Loader**
* **Fabric API**
* **oωo (owo-lib)**
* **Fabric Language Kotlin**
* **Plasma Voice** *(Required for voice control features)*

### Supported Versions
* **1.21.x** — Active development & main support.
* **1.20.1 – 1.20.6** — Legacy versions (Archived, no active updates).

> ⚠️ **Performance Tip:** Mass block destruction can cause lag spikes! We strongly recommend using client/server optimization mods such as **Sodium** and **Lithium**.
